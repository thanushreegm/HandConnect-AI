# ✨ HandConnect AI

### Real-Time Hand Tracking and Gesture Recognition

HandConnect AI is a browser-based computer vision application that detects hand movements in real time using a webcam.

## 🚀 Features

- Real-time hand tracking using MediaPipe
- Detection of up to two hands
- 21 hand landmarks per hand
- Neon hand skeleton visualization
- Basic gesture recognition
- Animated fingertip particle effects
- FPS monitoring
- Gesture history
- Webcam recording with tracking effects

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- MediaPipe Hands
- Canvas API
- Webcam API
- MediaRecorder API

## 💻 How to Run

1. Download or clone this repository.
2. Open `handconnect.html` using Visual Studio Code.
3. Install the Live Server extension.
4. Run the HTML file using Live Server.
5. Allow webcam access.
6. Click Start Camera.

## 🧠 How It Works

1. The webcam captures video.
2. MediaPipe detects hand landmarks.
3. JavaScript processes landmark coordinates.
4. Canvas draws the hand skeleton and visual effects.
5. Gesture recognition identifies basic hand movements.

## 📌 About

This project demonstrates real-time computer vision integration using a pretrained MediaPipe hand-tracking model.
